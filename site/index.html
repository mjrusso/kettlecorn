Kettlecorn runs Elixir and Erlang in a WebAssembly sandbox. Use it from Elixir, Rust, or the command line to isolate user code, plugins, and whole Mix applications. Each VM has a private filesystem and retains state across evaluations.

Getting started

  • Rust quickstart
  • Command-line guide

Kettlecorn is experimental. Read the sandbox guide before running untrusted code. The source is on GitHub.
