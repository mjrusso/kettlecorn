## In this repository

The Nix build fetches third-party sources from pinned flake inputs
(`flake.lock`) and nixpkgs. The files below reference or modify those sources:

* [`patches/otp/`](patches/otp): changes to
  [Erlang/OTP](https://github.com/erlang/otp) (Apache-2.0), applied on top of
  [Popcorn](https://github.com/software-mansion/popcorn)'s OTP patches
  (Apache-2.0, Copyright Software Mansion). Some of them modify code that
  Popcorn's patches add, and so they contain excerpts of it as context.
  `c/nif/kettlecorn_bridge.c` and `c/nif/kettlecorn_wasm_nif.c` also adapt
  message delivery and NIF registration from Popcorn's `wasm_nif.c`.
* [`c/http/world.wit`](c/http/world.wit) imports WASI interfaces whose WIT
  files come, at build time, from [wasmtime](https://github.com/bytecodealliance/wasmtime)
  (Apache-2.0 WITH LLVM-exception).

## In the built runtime

`nix build .#runtime` produces a runtime that contains, compiled or as
`.beam` files, the components below. Their license files (and NOTICE files,
where a component has one) are in the runtime's `licenses/<component>/`
directory. Distribute that directory with the runtime.

| Component | How it is included | License |
|---|---|---|
| [Erlang/OTP](https://github.com/erlang/otp) 29.1.2 | the emulator (`beam.wasm`, `beam-http.wasm`) and the kernel, stdlib, compiler, crypto, asn1, public_key and ssl applications, built with Popcorn's and Kettlecorn's patches | Apache-2.0 (and the licenses in `licenses/otp/LICENSES`) |
| [Popcorn](https://github.com/software-mansion/popcorn) | its OTP patches, compiled into the emulator | Apache-2.0 |
| [Elixir](https://github.com/elixir-lang/elixir) 1.20 | the elixir, logger, iex, eex and ex_unit applications | Apache-2.0 (and the licenses in `licenses/elixir/LICENSES`) |
| [wasi-libc](https://github.com/WebAssembly/wasi-libc) | statically linked into the emulator | Apache-2.0 WITH LLVM-exception, Apache-2.0, MIT |
| [LLVM compiler-rt](https://github.com/llvm/llvm-project) builtins | statically linked into the emulator | Apache-2.0 WITH LLVM-exception |
| [OpenSSL](https://www.openssl.org) 3.5 | statically linked into the emulator (`:crypto`) | Apache-2.0 |
| [Req](https://github.com/wojtekmach/req), [Finch](https://github.com/sneako/finch), [Mint](https://github.com/elixir-mint/mint), [HPAX](https://github.com/elixir-mint/hpax), [Jason](https://github.com/michalmuskala/jason), [MIME](https://github.com/elixir-plug/mime), [NimbleOptions](https://github.com/dashbitco/nimble_options), [NimblePool](https://github.com/dashbitco/nimble_pool), [Telemetry](https://github.com/beam-telemetry/telemetry) | `.beam` files from Hex (`guest/hex/mix.lock`) | Apache-2.0, except Finch (MIT). The native launcher embeds [Wasmtime](https://github.com/bytecodealliance/wasmtime)
(Apache-2.0 WITH LLVM-exception) and its locked Rust dependencies
(`launcher/Cargo.lock`). Their license and notice information is included under
`licenses/launcher/<crate>/`. Wasmtime is part of each platform runtime archive.

A cooked application (`Kettlecorn.Cook`) adds that application's
dependencies to the guest. Their licenses are the cooking project's
responsibility.
